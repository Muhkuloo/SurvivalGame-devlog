#  Hiisi – devlog

Kehityspäiväkirja PC:lle tulevasta co-op-selviytymispelistä (työnimi *Project Hiisi*). Pelissä on avoin saarimaailma, laaja tukikohdan rakentaminen ja tukikohdan puolustaminen ystävien kanssa. Hengeltään se muistuttaa Valheimia ja Sons of the Forestia.

- **Tekniikka:** Unity 6 (URP), Netcode for GameObjects, ensimmäinen persoona
- **Lähdekoodi:** yksityinen. Tässä repossa on vain edistymisen kuvaus.
